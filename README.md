# Python AI Experiments (15–20)

## About the Project
This repository contains Python programs based on Artificial Intelligence (AI), search algorithms, and game-playing techniques. These experiments demonstrate basic problem-solving approaches and AI concepts using Python.

## Experiments Included

| Experiment | Title | Concept Used |
|---|---|---|
| 15 | Chatbot Implementation | Conditional Statements and Loops |
| 16 | Missionaries and Cannibals Problem | Breadth-First Search (BFS) |
| 17 | 8-Puzzle Problem | A* Search Algorithm |
| 18 | Water Jug Problem | Breadth-First Search (BFS) |
| 19 | Tic-Tac-Toe Game | Game Logic and Conditional Statements |
| 20 | AI-Based Tic-Tac-Toe | Minimax Algorithm |

## Technologies Used
- Python 3
- `collections` module
- `heapq` module
- Basic AI search techniques

## How to Run
1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the required Python file:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the experiment file.

## Learning Outcomes
- Understand basic Artificial Intelligence concepts.
- Implement search algorithms such as BFS and A*.
- Solve classic AI problems using Python.
- Understand game-playing strategies using Minimax.
- Improve programming and logical problem-solving skills.
